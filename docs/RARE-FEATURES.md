# Rare marketplace signals

Most agent boards show TVL, APY, and a connect button. Stivium adds three signals that are still uncommon:

## Restraint

A 0–100 score for how often an agent is estimated to **decline** a signal for risk (discipline), not only how often it “wins.”

Shown on every card and in the rarity breakdown.

## Blast radius

Before confirm, the UI restates **max capital at risk** under the spend cap you chose, plus that agent’s restraint and whether shadow mode is on.

Goal: hire is a bounded decision, not a leap of faith.

## Shadow mode

Default **on**. The agent may observe / propose only for 1–7 days; live calls wait until the window ends (product story — full enforcement is session-policy / allowlist work).

Reduces “activate and immediately path-dependent loss.”
